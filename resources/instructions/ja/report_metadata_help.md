# メタデータレポート - クイックガイド

メタデータパイプラインが生成した一時 JSON から HTML レポートを再生成し、フライトをベクター化するツールです。

利用可能な JSON のリストは一時レポートフォルダーから自動的に読み込まれ、新しいものから古いものへ並べられます。

## ツールの機能

- **レポートを生成** - 選択した JSON から HTML レポートを生成し、ファイルを自動的に開きます。
- **フライトをベクター化** - JSON から点レイヤー（`Flight_...`）を作成し、対応するトラック（ライン）レイヤーを生成します。
- **更新ボタン** - 利用可能な一時 JSON のリストを更新します。
- **フォルダーを開く** - 一時 JSON フォルダーまたは HTML レポートフォルダーを開きます。

## 使い方

1. `Cadmus > メタデータレポート` を開きます。
2. リストから一時 JSON ファイルを選択します（新しいものから古いものへ）。
3. アクションを選択します:
   - `レポートを生成` をクリックすると、HTML レポートを生成して開きます。
   - `フライトをベクター化` をクリックすると、プロジェクトに点レイヤーとトラックレイヤーを作成します。
4. 必要に応じて補助ボタンを使用します:
   - `リストを更新` - 利用可能な JSON を再読み込みします。
   - `JSON フォルダーを開く` - 一時 JSON ファイルが保存されているフォルダーを開きます。
   - `レポートフォルダーを開く` - 生成された HTML レポートが保存されているフォルダーを開きます。

## プラグインが実際に行うこと

- 一時レポートフォルダー（`REPORTS_TEMP_FOLDER` + `REPORTS_JSON_FOLDER`）から `.json` ファイルを読み取り、変更日時で並べ替えます（新しいもの優先）。
- コンボボックスに各 JSON ファイルの名前を表示します。選択内容はツール設定に保存されます。
- **レポートを生成**:
  - JSON が選択されていること、ファイルが存在することを検証します。
  - ライセンスがレベル 3 以上であることを確認します（`RegistryManager.has_minimum_level`）。
  - `ReportGenerationService.generate_from_json()` を使用して HTML を生成し、ペイロードからパスを取得します。
  - `ExplorerUtils.open_file()` で HTML を自動的に開きます。
- **フライトをベクター化**:
  - `JsonToVectorTranslator.translate()` を使用して点レイヤーを作成します。
  - レイヤー名は `Flight_<タイトル>`（JSON の `titulo` フィールド）または `Flight_<ファイル名>`（フォールバック）です。
  - 座標ソースは JSON の `source` フィールドから読み取ります（デフォルト `mrk+photo`）。
  - レイヤーのフィールドはアルファベット順に並べ替えられます。
  - 点レイヤーがプロジェクトに追加されます。
  - 写真フィールド（Foto/PhotoNum/id）で並べ替え、`MrkPath` + `MrkFile` でグループ化して、点からトラック（ライン）レイヤーを生成します。
  - バーに `フライトがベクター化されました: N ポイントとトラックが生成されました` と表示します。

## 重要な挙動

- レポートの生成にはライセンスレベル 3 以上が必要です。ない場合は警告が表示されます。
- JSON が選択されていない、またはファイルが存在しない場合、警告が表示されます（`ファイルを選択` / `ファイルが見つかりません`）。
- JSON リストが空の場合があります。パイプラインで新しい JSON を生成した後は `リストを更新` を使用してください。
- 生成された HTML レポートは自動的に開かれます。開けない場合は警告バーが表示されます。
- 一時 JSON には、レポートとベクター化の両方で使用されるフライトのメタデータ（タイトル、座標ソース、写真、マーク）が含まれます。

## どんなときに使うか

次のような場合に使用します:

- パイプライン全体を再処理せずに、フライトの HTML レポートを再生成するとき
- 処理済みのフライトをベクター化して、点レイヤーとトラックレイヤーを再作成するとき
- 一時 JSON フォルダーと HTML レポートフォルダーにすばやくアクセスするとき

## 注意点

- ベクター化はプロジェクトにレイヤーを追加します。同じ名前のレイヤーが既に存在しないか確認してください。
- レポートの生成はブラウザで HTML を開きます。レポートフォルダーが存在するか確認してください。
- JSON リストは手動（`リストを更新` ボタン）またはツールを開いたときのみ更新されます。
- ライセンス: レポート生成にはレベル 3 が必要です。ベクター化にはそのレベルは不要です。
