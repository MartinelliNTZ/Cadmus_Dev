# パス拡張子 - クイックガイド

ベクターレイヤーのフィーチャに保存されたパス内のファイル拡張子を削除・復元したり、写真を ZIP 圧縮・解凍したりするツールです。

ファイルパスはレイヤーのフィールドから読み取られ、各操作の結果は `NewPath` フィールド（自動作成）に書き込まれます。

## 操作モード

- `拡張子を削除` - 物理パスからドットと拡張子を削除します。例: `C:/fotos/foto.jpg` は `C:/fotos/fotojpg` になります。ディスク上のファイルはリネームされます。
- `拡張子を復元` - ドットと拡張子を復元します。例: ディスク上の `C:/fotos/fotojpg` は再び `C:/fotos/foto.jpg` になります。
- `ZIP 圧縮` - 同じフォルダーのフィーチャをグループ化し、フィーチャが参照するファイルを含む ZIP ファイルをフォルダーごとに 1 つ作成します。圧縮後に元のファイルを削除します。
- `ZIP 解凍` - 同じフォルダーのフィーチャをグループ化し、フォルダーの ZIP を展開して、展開後に ZIP を削除します。

## 使い方

1. `Cadmus > パス拡張子` を開きます。
2. 入力ベクターレイヤーを選択します（必要に応じてベクターファイルも可）。
3. オプション: `選択フィーチャのみ` をチェックすると、現在の選択範囲だけを処理します。
4. ファイルパスを含むフィールドを選択します。レイヤーに `path` という名前のフィールドがある場合は自動選択されます。
5. 操作モード（削除、復元、ZIP 圧縮、ZIP 解凍）を選択します。
6. `実行` をクリックします。
7. 最後に、変更されたフィーチャ数とともに成功メッセージがメッセージバーに表示されます。

## プラグインが実際に行うこと

- インターフェースからレイヤーと選択したパスフィールドを読み取ります。
- レイヤーがベクターであること、属性が選択されていること、モードが選択されていることを検証します。
- 非同期パイプライン（`AsyncPipelineEngine` + `PathExtensionStep`）を実行します。
- タスクはレイヤーに触れずにディスク上の物理ファイルを処理します:
  - `remove` と `restore` は `ExplorerUtils` 経由でフィーチャごとに処理します。
  - `zip` と `unzip` はフィーチャをフォルダーごとにグループ化し、`FileCompressUtils` に委任します。
- ステップは `NewPath`（テキスト）フィールドをレイヤーに追加します（まだ存在しない場合）。
- 完了時、ステップは各フィーチャの `NewPath` フィールドに結果の新しいパスを書き込み（メインスレッド）、レイヤーを再描画します。
- メッセージバーに `処理が完了しました: N フィーチャが変更されました` と表示します。
- 最後に使用したモードをツールの設定に保存します。

## 重要な挙動

- `NewPath` はレイヤーに作成され、処理された各フィーチャの新しいパスを受け取ります。スキップされたフィーチャやエラーのフィーチャは変更されません。
- `ZIP 圧縮` モード: ZIP はフォルダー名で作成され（例: `C:/fotos/fotos.zip`）、フィーチャが参照するファイルのみを含みます（フォルダーの全ファイルではありません）。
- `ZIP 解凍` モード: フォルダーの ZIP はディレクトリ自体に展開され、その後 ZIP ファイルは削除されます。
- パスが空または無効な場合、そのフィーチャはエラーとしてカウントされます。
- ファイルが存在しない、または権限が拒否された場合もエラーとしてカウントされますが、残りのフィーチャの処理は続行されます。
- 処理は非同期で、インターフェースはフリーズしません。実行中にタスクをキャンセルできます。

## どんなときに使うか

次のような場合に使用します:

- 写真のパスを一括で正規化する（拡張子の削除または復元）とき
- レイヤーのフィーチャが参照するファイルを ZIP に圧縮するとき
- フィーチャが参照する ZIP を展開して元のファイルを復元するとき

## 注意点

- `ZIP 圧縮` モードは ZIP 作成後に元のファイルを削除します。必要に応じてバックアップを作成してください。
- `ZIP 解凍` モードは展開後に ZIP を削除します。
- 選択したフィールドが有効な絶対パスを実際に含んでいるか確認してください。
- レイヤー全体を処理する前に、`選択フィーチャのみ` で小さなセットをテストしてください。
- 処理はディスク上のファイルを変更します。実行前にフォルダーを確認してください。
