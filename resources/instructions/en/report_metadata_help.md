# Metadata Report — Quick Guide

Tool to regenerate HTML reports and vectorize flights from temporary JSONs generated by the metadata pipeline.

The list of available JSONs is loaded automatically from the temporary reports folder, sorted from newest to oldest.

## What the tool does

- **Generate report** — generates an HTML report from the selected JSON and opens the file automatically.
- **Vectorize flight** — creates a point layer (`Flight_...`) from the JSON and generates the corresponding track (line) layer.
- **Refresh button** — updates the list of available temporary JSONs.
- **Open folders** — opens the temporary JSONs folder or the HTML reports folder.

## How to use

1. Open `Cadmus > Metadata Report`.
2. Select a temporary JSON file from the list (newest to oldest).
3. Choose an action:
   - Click `Generate Report` to generate and open the HTML report.
   - Click `Vectorize Flight` to create the point and track layers in the project.
4. Use the auxiliary buttons if needed:
   - `Refresh list` — reloads the available JSONs.
   - `Open JSONs folder` — opens the folder where the temporary JSON files are stored.
   - `Open reports folder` — opens the folder where the generated HTML reports are stored.

## What the plugin actually does

- Reads the `.json` files from the temporary reports folder (`REPORTS_TEMP_FOLDER` + `REPORTS_JSON_FOLDER`), sorted by modification date (newest first).
- The combo shows the name of each JSON file; the selection is saved in the tool preferences.
- **Generate report**:
  - Validates that a JSON was selected and that the file exists.
  - Checks that the license has minimum level 3 (`RegistryManager.has_minimum_level`).
  - Uses `ReportGenerationService.generate_from_json()` to generate the HTML and gets the path from the payload.
  - Opens the HTML automatically with `ExplorerUtils.open_file()`.
- **Vectorize flight**:
  - Uses `JsonToVectorTranslator.translate()` to create the point layer.
  - The layer name is `Flight_<title>` (from the JSON `titulo` field) or `Flight_<file name>` as fallback.
  - The coordinate source is read from the JSON `source` field (default `mrk+photo`).
  - The layer fields are reordered alphabetically.
  - The point layer is added to the project.
  - Generates the track (line) layer from the points, ordered by photo field (Foto/PhotoNum/id) and grouped by `MrkPath` + `MrkFile`.
  - Shows in the bar: `Flight vectorized: N points and track generated.`

## Important behavior

- Generating a report requires license level 3 or higher; without it, the tool shows a warning.
- If no JSON is selected or the file does not exist, the tool shows a warning (`Select a file` / `File not found`).
- The JSON list can be empty — use `Refresh list` after generating new JSONs in the pipeline.
- The generated HTML report is opened automatically; if it fails to open, a warning bar is shown.
- The temporary JSON contains the flight metadata (title, coordinate source, photos and marks) used both by the report and the vectorization.

## When to use it

Use this tool when you want to:

- regenerate an HTML report of a flight without reprocessing the whole pipeline;
- vectorize an already processed flight, recreating the point and track layers;
- quickly access the temporary JSONs and HTML reports folders.

## Notes

- Vectorization adds layers to the project — check that layers with the same name do not already exist.
- Generating a report opens the HTML in the browser; check that the reports folder exists.
- The JSON list is only updated manually (`Refresh list` button) or when opening the tool.
- Licensing: generating reports requires level 3; vectorization does not require that level.
