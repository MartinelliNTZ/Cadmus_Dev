# Cadmus 設定 - クイックガイド

このツールは、Cadmus プラグインの各部分で使用されるグローバル設定を一元管理します。

現在のコードでは、次のことができます:

- Cadmus プロジェクトのルートフォルダーを設定する;
- デフォルトの CRS（座標参照系）を選択する;
- インターフェース言語を設定する（または QGIS の言語を自動検出する）;
- デフォルトのベクター計算方法を選択する（楕円体、平面、両方）;
- 平面および楕円体の面積フィールドのサフィックスを定義する;
- ベクターフィールドの数値精度を定義する;
- 非同期処理のフィーチャー閾値を定義する;
- ツールバーに表示するツールカテゴリを制御する;
- ローカルの Cadmus 設定フォルダーを開く。

## 使い方

1. `Cadmus > Configuracoes Cadmus` を開きます。
2. **一般** セクション:
   - プロジェクトフォルダーを設定します（任意）。
   - デフォルトの CRS を選択します（推奨: EPSG:4326 WGS84）。
   - インターフェース言語または `自動検出` を選択します。
   - ベクターフィールドの精度を調整します（0〜10 桁）。
   - 非同期閾値を調整します（1〜100000000 フィーチャー）。
   - ツールバーに表示するカテゴリをチェック/チェック解除します。
3. **ベクター計算** セクション:
   - 計算方法を選択します: `楕円体`、`平面`、または `両方`。
   - 面積フィールドのサフィックスを設定します（平面および楕円体）。
4. `保存` をクリックします。

## プラグインが実際に行うこと

- `load_tool_prefs()` で保存済みの設定を読み込みます。
- 設定を **3 つの** 設定キーに保存します:
  - `SYSTEM` キー（グローバルアプリケーション設定）;
  - `VECTOR_FIELDS` キー（面積サフィックス）;
  - `settings` キー（ウィンドウ状態と折りたたみセクション）。
- 平面サフィックスと楕円体サフィックスが同じでないことを検証します。同じ場合は保存をキャンセルし、警告を表示します。
- 保存後に確認メッセージを表示します。
- 新しく選択した言語で翻訳文字列を再読み込みします。
- 設定を適用した直後にウィンドウを閉じます。
- 設定ファイルが保存されているローカルフォルダーを開くことができます。
- ツールバーカテゴリの表示が変更された場合、ツールバーを動的に更新するシグナルを送信します。

## 各オプションの意味

- `プロジェクトフォルダー`: パスを `projects_folder` に保存します。
- `デフォルト CRS`: authid（例: `EPSG:4326`）を `default_crs_authid` に保存します。
- `言語`: ロケール（例: `pt_BR`）を `plugin_language` に保存します。`自動検出` の場合はキーを削除して QGIS に決定させます。
- `ベクター計算方法`: テキストを `calculation_method` に保存します。
- `平面サフィックス`: `cartesian_suffix`（`VECTOR_FIELDS` キー）に保存します。
- `楕円体サフィックス`: `ellipsoidal_suffix`（`VECTOR_FIELDS` キー）に保存します。
- `ベクターフィールドの精度`: 整数値を `vector_field_precision` に保存します。
- `非同期閾値`: 整数値を `async_threshold_features` に保存します。
- `ツールバー - 表示カテゴリ`: カテゴリの辞書を `toolbar_category_visibility` に保存します。

## ベクター計算方法（楕円体 vs 平面）

### 楕円体（WGS84 / 地理座標系に推奨）

地球の楕円体の**曲面**上で面積と長さを計算します（例: WGS84）。
- **地理座標系（緯度/経度）のレイヤーに最適**（WGS84 / EPSG:4326 など）。
- 結果はレイヤーの CRS に関係なく**メートル / 平方メートル**です。
- 地球の曲率を考慮するため、広い面積や高緯度でより正確です。
- **例**: EPSG:4326 でこの方法により計算された面積は、m² で実際の物理値を返します。

### 平面（UTM / 投影座標系に推奨）

レイヤーの CRS の**平面**上で面積と長さを計算します。
- **UTM などの投影座標系に最適**（例: EPSG:31983 SIRGAS 2000 / UTM 23S）。単位はすでにメートルです。
- 平面計算のみを使用するため、高速でシンプルです（ピタゴラスの定理 / 外積）。
- **注意**: 地理座標系（度）では、平面計算は**度 / 度²** の値を生成し、物理的な意味がありません。
- 地理レイヤーで平面モードが要求された場合、プラグインは自動的に `両方` に切り替えて警告を表示します。

### 両方

両方の方法を同時に計算します。
- 各メトリックに対して**2 つの別々のフィールド**を生成します（1 つは平面、1 つは楕円体）。
- 下で設定したサフィックスを使用してフィールドを区別します。
- 結果の比較とデータ品質の検証に役立ちます。

## ツールチップ（ウィジェットの説明）

設定フィールドにマウスを合わせると、詳細な説明が表示されます:

- **プロジェクトフォルダー**: Cadmus プロジェクトが作成・整理されるルートフォルダー。新しいプロジェクトや入出力ファイルのデフォルトの場所として使用されます。
- **デフォルト CRS**: CRS が指定されていない場合に使用される参照系。WGS84（EPSG:4326）はグローバルデータの推奨デフォルトです。
- **言語**: インターフェース言語を定義します。`自動検出` は QGIS の言語を使用します。
- **ベクターフィールドの精度**: 面積、長さ、X/Y 座標で使用される小数点以下の桁数。値が大きいほど精度は上がりますが、フィールドが長くなります。
- **非同期閾値**: 処理がバックグラウンドで実行されるための最小フィーチャー数。閾値より小さいレイヤーは同期（ブロッキング）で実行されます。
- **ツールバー - 表示カテゴリ**: ツールバーに表示されるツールカテゴリを制御します。チェックを外すとボタンが非表示になります。
- **計算方法**: 楕円体（WGS84/地理座標系に最適）、平面（UTM/投影座標系に最適）、または両方。
- **平面サフィックス**: 平面モードで計算されたフィールドに追加されるテキスト。空 = サフィックスなし。
- **楕円体サフィックス**: 楕円体モードで計算されたフィールドに追加されるテキスト。デフォルトは `_eli` で、平面フィールドと区別します。

## 重要な挙動

- 現在の非同期閾値は MB ではなくフィーチャー数で測定されます。
- 精度は 0〜10 の値を受け入れます。
- 非同期閾値は 1〜100000000 の値を受け入れます。
- 古い `async_threshold_bytes` キーの読み取りには後方互換性がありますが、読み込み後はフィーチャーベースの制限を使用します。
- 平面サフィックスと楕円体サフィックスは同じにできません。同じ場合は警告とともに保存がブロックされます。
- このプラグインは設定を保存するだけです。ベクター計算自体は実行しません。

## 設定フォルダー

- インターフェースのリンクは、オペレーティングシステムで `PREF_FOLDER` を開こうとします。
- フォルダーが存在しない場合、プラグインはファイルエクスプローラーを開く代わりに警告を表示します。

## どんなときに使うか

これらのグローバル設定に依存する他の Cadmus ツールのデフォルト動作を調整したいときに使用します。

## 注意点

- 計算方法は、ワークフローに合う場合にのみ変更してください。
- 非同期閾値を下げすぎると、より多くの操作がバックグラウンドで実行される可能性があります。
- 設定変更後に予期しない動作が発生した場合は、設定フォルダーに保存されたファイルを確認してください。
